## What I work on

- **Web scraping:** sites with anti-bot protection, public registries, marketplaces. Playwright, httpx, curl_cffi, Selenium.
- **Data pipelines:** extraction, cleaning, OCR and structured exports, plus bulk uploads to Shopify and WooCommerce.
- **Automation and backends:** FastAPI services, scheduled jobs, retry logic, Docker.
